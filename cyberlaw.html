E-Commerce

Likely questions and checklist

Browse, add to cart, checkout, payment via gateway and bank authorisation, order confirmation, fulfilment and after-sales support.

Unit II

Web security and firewalls

Security issues on web, importance of firewall, components of firewall, transaction security, emerging client-server, security threats, network security, factors in firewall design, limitations of firewalls.

Security issues on the web

Three goals matter, called the CIA triad: Confidentiality, Integrity, and Availability.

  • Client side: malicious scripts, cookie theft, phishing, malware downloads.
  • Server side: SQL injection, XSS, weak passwords, misconfiguration, DoS and DDoS.
  • Network side: sniffing, spoofing and man-in-the-middle attacks.

Firewall: importance and components

A firewall is a barrier between a trusted network and an untrusted network. It checks traffic against rules and allows or blocks it.

ComponentRole
Packet filterChecks source/destination IP, port and protocol
Application gatewayActs as a proxy and inspects application content
Circuit-level gatewayValidates sessions and handshakes
Bastion hostHardened computer that runs proxy services
DMZMiddle zone for public web and mail servers

Types of firewall

  • Packet filtering: fast, simple, examines headers.
  • Stateful inspection: remembers connection state.
  • Proxy/application firewall: inspects application data.
  • Next-generation firewall: combines stateful inspection, application awareness and intrusion prevention.

Transaction security and threats

Online payment needs confidentiality, authenticity, integrity and non-repudiation. Tools include SSL/TLS, certificates, digital signatures, payment gateways, OTP/2FA and tokenisation.

ThreatMeaning
SpoofingFaking an identity or IP address
SniffingCapturing data on the network
PhishingFake pages or mails that steal credentials
DoS / DDoSFlooding a server so real users cannot access it
Man-in-the-middleSecretly relaying and altering traffic

Firewall design and limitations

Design factors: security policy, network topology, DMZ placement, firewall type, performance, logging, maintenance and fail-safe behaviour. Prefer default deny.

Limitations

A firewall cannot stop insider attacks, phishing, social engineering, weak passwords or encrypted malware. It can only control traffic that passes through it.

Likely questions

What is a firewall? Explain its importance and components.

A system at the trusted/untrusted network boundary that filters traffic. Components include screening routers, application gateways, circuit gateways, bastion hosts, DMZ and logging.

State the limitations of firewalls.

No protection from insiders, bypass routes, social engineering or compromised hosts; effectiveness depends on correct rules and maintenance.

Unit III

Encryption and digital signatures

Encryption techniques, symmetric keys and DES, triple DES, asymmetric encryption, secret key and public/private key encryption, digital signatures, VPN, technical and legal issues, electronic records and contracts.

Encryption basics

Encryption converts plaintext into ciphertext using an algorithm and key. Decryption reverses it. A substitution cipher replaces symbols; a transposition cipher rearranges symbols.

Symmetric encryption: DES and Triple DES

The same key encrypts and decrypts. It is fast but requires safe key distribution.

DESTriple DES (3DES)AES
Block size64 bits64 bits128 bits
Key56 bits112 or 168 bits128, 192 or 256 bits
Rounds16Three DES operations10, 12 or 14
StatusBrokenRetired or being retiredCurrent standard

DES: 64-bit blocks, 56-bit effective key and 16 Feistel rounds. 3DES: commonly encrypt-decrypt-encrypt with two or three keys.

Outdated

DES and 3DES are replaced by AES in practice. Learn them for the exam.

Asymmetric encryption

Each user has a public key shared openly and a private key kept secret. RSA uses the difficulty of factoring large primes.

SymmetricAsymmetric
KeysOne shared keyPublic/private pair
SpeedFastSlow
Key sharingDifficultEasy
ExamplesDES, 3DES, AESRSA, ECC, Diffie-Hellman

RSA toy example: p=3, q=11, n=33, phi=20, e=7, d=3. Public key=(7,33); private key=(3,33). Plaintext 4 encrypts to ciphertext 16 and decrypts to 4.

HTTPS uses a hybrid system: asymmetric encryption establishes or protects a session key, then symmetric encryption protects the actual data.

Digital signatures

A digital signature proves the sender's identity, integrity and non-repudiation. It does not itself encrypt the message.

  • 1. HashGenerate SHA-256 digest
  • 2. SignEncrypt digest with sender private key
  • 3. SendMessage and signature
  • 4. VerifyReceiver checks with sender public key

A digital certificate (X.509) issued by a Certifying Authority binds a public key to an identity.

Legal issues

  • IT Act 2000, Sec 3/3A: authentication using digital or electronic signatures.
  • Sec 4: legal recognition of electronic records.
  • Sec 5: legal recognition of digital signatures.
  • Sec 10A: validity of electronic contracts.
  • Evidence: electronic evidence is governed by the Bharatiya Sakshya Adhiniyam, 2023.

Digital contracts still require offer, acceptance, consideration, capacity and free consent.

Virtual Private Network (VPN)

A VPN creates an encrypted tunnel across a public network. It provides confidentiality, integrity and remote or branch-office access. Common protocols include IPsec, SSL/TLS and WireGuard.

Likely questions

Explain symmetric and asymmetric encryption with differences.

Symmetric uses one shared key and is fast; asymmetric uses public/private pairs and is slower. Asymmetric solves key distribution and supports signatures.

Explain DES and Triple DES.

DES: 64-bit blocks, 56-bit key, 16 Feistel rounds. 3DES applies DES three times. Both are now superseded by AES.

What is a digital signature? How is it created and verified?

Hash the message, encrypt the digest with the sender private key, then verify the signature using the sender public key.

Unit IV

Cyber law and intellectual property

Jurisprudence of cyber law, object and scope of IT Act 2000, Indian cyber law, UNCITRAL Model Law, ISP guidelines, IPR issues and cyberspace, Indian perspective, patent, copyright, trademark and semiconductor layout.

Jurisprudence and the IT Act 2000

Jurisprudence is the philosophy and science of law. Cyber law regulates internet use, computers, electronic data and online conduct.

The Information Technology Act, 2000 came into force on 17 October 2000 and was substantially amended in 2008.

Object and scope

  • Give legal recognition to electronic records and digital signatures.
  • Facilitate e-commerce, e-governance and electronic payments.
  • Define cyber offences and prescribe penalties.
  • Recognise intermediaries and establish a legal framework for electronic evidence.

Struck down or replaced

Section 66A was struck down in Shreya Singhal v Union of India (2015). The Cyber Appellate Tribunal was replaced/merged under later law.

UNCITRAL Model Law and ISP guidelines

The UNCITRAL Model Law on Electronic Commerce was adopted in 1996. It uses functional equivalence and technology neutrality so electronic records receive treatment similar to paper records.

ISPs need a licence from the Department of Telecommunications. Typical duties include lawful interception, log retention for a notified period, subscriber verification and timely cooperation with authorities.

Likely questions

Explain the object and scope of the IT Act 2000.

Legal recognition for e-records, signatures and e-commerce; e-governance; electronic payments; cyber offences and penalties; intermediary rules.

Write a note on the UNCITRAL Model Law.

Adopted in 1996 to harmonise e-commerce laws through functional equivalence, non-discrimination and technology neutrality.

Differentiate patent, copyright and trademark.

Patent protects inventions for up to 20 years; copyright protects original expression for life plus 60 years; trademarks protect brand identity for renewable 10-year periods.

Unit V

Cyber crime and internet security threats

Cyber crime, jurisdiction, evidence, treatment in different countries, ethical issues in data and software privacy, plagiarism, pornography, tampering, data privacy, domain names, software piracy, ethical hacking, biometrics.

Cyber crime and jurisdiction

Cyber crime is illegal conduct where a computer or network is the target, tool or place of the crime. It may be against persons, property, governments or the state.

Cyber jurisdiction: place of the offender, victim or affected system may be relevant, as may effects, server location and laws of involved countries.

International comparison: USA — CFAA; UK — Computer Misuse Act 1990; EU — GDPR and NIS rules; India — IT Act, BNS and data-protection law; Singapore — Computer Misuse Act.

Cyber crime and evidence

Digital evidence includes logs, e-mails, chats, hard disks, CCTV and call records. Preserve it using chain of custody, write-blockers, hashes and forensic copies. Hashes prove that copies match originals.

Ethical issues

  • Data and software privacy: collect and use personal data with consent and purpose limitation.
  • Plagiarism: using another person's words, ideas or code and claiming them as one's own.
  • Pornography: sexual content; distribution or possession may be illegal where prohibited, especially involving minors.
  • Tampering: unauthorised alteration or deletion of data or systems.
  • Software piracy: unauthorised copying or use of software.

Domain names and DNS

The Domain Name System maps names to IP addresses. Cybersquatting registers a famous name to exploit or sell it. UDRP provides a system for dispute resolution over domain names.

Ethical hacking

Ethical hacking is authorised penetration testing to find weaknesses before criminals do. White hat works with permission; grey hat has uncertain or limited authority; black hat acts maliciously or illegally.

Internet security threats

ThreatMeaning

Defence: updated antivirus, patches, firewall, backups, strong unique passwords with 2FA, least privilege and security awareness.

Remember

Virus needs a host and usually a user action; worm spreads alone; Trojan tricks the user; logic bomb waits for a trigger.

Biometric security

Biometrics identify a person by fingerprint, face, iris, voice or behaviour. Enrolment creates a template; later input is matched with that template.

  • Challenges: false accept/reject errors, spoofing, worn or dirty sensors, and irreversible identity data if a template leaks.
  • Use liveness detection, encryption, template protection and a backup authentication method.

Likely questions

What is cyber crime? Explain its types and jurisdiction problems.

Crime using a computer as target, tool or location; classify it against persons, property or government; courts must resolve locations, effects and applicable law.

Differentiate virus, worm, Trojan and logic bomb.

A virus attaches to files, a worm spreads autonomously, a Trojan masquerades as useful software, and a logic bomb waits for a trigger.

What is ethical hacking?

Authorised testing to find weaknesses; white hats have permission and a defined scope, while black hats act illegally.

Discuss biometric security and its challenges.

Identity is established through traits such as fingerprint or face; challenges include spoofing, error rates and the inability to replace leaked biological identifiers.
